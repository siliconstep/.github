## 关于

<sub>名字取自《荀子·劝学》:"不积跬步,无以至千里" —— 硅基的每一步,都会走向千里。</sub>
<sub>Cadenza是音乐术语，指歌剧咏叹调末尾处由独唱者即兴发挥的段落，或协奏曲乐章末尾处由独奏者发挥其表演技巧的段落。</sub>
